# Báo cáo hiện trường

Ứng dụng web chạy trên điện thoại: ghi âm / quay clip / chụp ảnh tại hiện trường → AI (Google Gemini, khóa miễn phí) soạn báo cáo theo thể thức hành chính → đọc lại, sửa bằng giọng nói → xuất file Word (kèm phụ lục ảnh) + MP3 → gửi Zalo / Gmail.

Hai mẫu: **Báo cáo nhanh tình hình mưa lũ** (theo danh sách tuyến) và **Báo cáo kiểm tra 1 vị trí**.

Mở: https://nhanttt581-star.github.io/bao-cao-hien-truong/

Khóa AI và dữ liệu (ghi âm, ảnh, báo cáo) chỉ lưu trên điện thoại của người dùng.
